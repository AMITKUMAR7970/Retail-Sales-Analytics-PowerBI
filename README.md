# 📊 Retail Sales Analytics Dashboard | Power BI

## 📌 Project Overview

This project demonstrates how business data can be transformed into meaningful insights using Power BI. The report was developed by redesigning the data model into a star schema, creating reusable DAX measures, and building interactive dashboards to analyze sales performance, profitability, returns, and fulfillment metrics.

The objective is to help business stakeholders make informed decisions through data-driven insights.

---

## 🚀 Features

- ⭐ Redesigned the semantic model into a Star Schema
- 📅 Created a dedicated Calendar table for Time Intelligence
- 📈 Developed 17 DAX Measures
- 📊 Interactive KPI dashboards
- 📦 Sales & Profit Analysis
- 🚚 Fulfillment Performance Analysis
- 🔄 Return Analysis
- 📅 Year-over-Year Trend Analysis

## 📈 Key Business Insights

- Identified a loss-making product sub-category with **-9.3% profit margin**.
- Discovered **77% Year-over-Year sales growth**.
- Identified shipping delays affecting fulfillment performance.
- Delivered business recommendations through an executive-ready presentation.
